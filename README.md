# Coding Temple Bootcamp (2021)

Everything I built during the Coding Temple full-stack and data bootcamp in fall 2021. This was my first real stretch of programming after the Army, so it's a snapshot of where I started.

Each folder used to be its own repo. They were combined here with their original commit history kept.

## What's inside

| Folder | Topic | Projects |
|---|---|---|
| `01-python` | Python fundamentals | Day 1 basics, weekend project, ROI calculator, regular expressions |
| `02-sql` | SQL | Movie theater database |
| `03-flask` | Flask web apps | Flask practice app, Marvel API app with login and database |
| `04-javascript` | JavaScript and the DOM | Amazon clone, DOM homework, F1 race API, weather app |
| `05-data-science` | Pandas, NumPy, Jupyter | Matrix practice, Red Sox stats, NBA 2018-19 stats, Airbnb case study |
| `06-react` | React | Shopping cart, car shopping store, stock tracker |
| `07-portfolio` | Portfolio sites | React portfolio, HTML portfolio |

## Stack

Python, SQL (PostgreSQL), Flask, JavaScript, HTML/CSS, React, Pandas, NumPy, Jupyter
